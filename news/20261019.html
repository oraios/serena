Serena v2.1.0

2026-10-19

Important Fixes.

  • Restored Claude Desktop client compatibility in chat mode (code mode was unaffected).
  • Fixed dashboard and file logging when running the MCP server in HTTP mode, working around an MCP SDK configuration issue.

Expanded Language Server Support. Serena now supports VB.NET via a Roslyn-based language server. The new typescript_tsgo option provides access to TypeScript 7's native language server, with automatic installation of the TypeScript package.

See our change log for the full list of changes.
