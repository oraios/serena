Serena v2.0.0

2026-10-13

The Serena REPL. The new REPL interface lets agents access Serena's functionality through Python code: combine operations in one call, filter and process results, and reuse variables across calls. This reduces round-trips and saves context by keeping intermediate results out of the conversation. API details are retrieved on demand, and available operations can adapt during a session, including when switching language backends. The classic tool interface remains available.
See further details and configuration instructions.

Other Improvements.

  • Expanded language server and coding agent support.
  • Improved code intelligence, editing reliability and security.
  • Performance improvements and numerous fixes across language servers, project management, hooks and the dashboard.

See our change log for the full list of changes.
